# Xenorra website — editorial and bespoke illustration release

## Research basis
Xenorra Protocol Specification draft revision 1.0, November 2026 (included under assets). No measured benchmarks, production security audit, or mainnet deployment are claimed.

## Illustrations
18 original, page-specific SVG compositions. No image is reused as the main hero on another page. Portraits and faces have been removed from the main page hero artwork. Existing diagrams remain where they explain actual protocol concepts.

## Registration limitation / deployment blocker
The join form is a browser-local interest preview, not account registration. There is no shared database, password authentication, email verification, anti-spam, moderation backend, or production forum persistence. DO NOT advertise registration as live or collect passwords until a server-side provider is configured and tested.

## Pre-launch checklist
- Test every page at desktop and mobile widths in a real browser.
- Configure production authentication, verified email delivery, rate limits, abuse controls, secure session handling, and privacy notice.
- Connect forum and governance to a shared database with row-level access policies and moderation.
- Validate technical statements against the current protocol specification and independent security review.
- Check all external links, forms, accessibility, and deployment headers.
